AIB 1.0 概述

项目起源

AIB 1.0 是 AIB（AI 区块链）协议的第一个版本，基于 iobond/aib GitHub 仓库的研究开发。该项目旨在创建一个基于比特币技术、具有 AI 主题的加密货币。

技术特点

  • 代码库：基于比特币核心（C++）
  • 共识机制：工作量证明（PoW）
  • 代币供应量：2100 万固定供应
  • 区块奖励：类似比特币减半机制
  • 链 ID：传统 AIB1 链

发展历程

  • 2020 年：AIB 1.0 初始开发
  • 2021 年：社区建设和代币分发
  • 2024 年：规划 AIB 2.0 重大升级
  • 2026 年：AIB 2.0 启动，采用模块化架构

AIB 1.0 到 AIB 2.0 升级

升级原因

创建 AIB 2.0 是为了解决 AIB 1.0 的局限性：

  • 可扩展性：原有 PoW 链吞吐量有限
  • 灵活性：需要模块化架构以集成 AI
  • 治理：希望实现宪法约束的去中心化治理
  • 技术：采用 Go 语言实现以提高可维护性

主要改进

方面 AIB 1.0 AIB 2.0
架构 单体式（基于比特币） 模块化（Go 插件）
共识 PoW PoAIW（AI 工作证明）
语言 C++ Go
治理 无 宪法 + 投票
AI 集成 无 原生 ZKML 模块

迁移指南

AIB 1.0 持有者可以通过桥接机制将代币迁移到 AIB 2.0。迁移包括：

  • 快照：在特定区块高度记录代币余额
  • 认领：AIB1 持有者可以领取等值的 AIB2 代币
  • 归属：部分迁移代币可能有归属期

查看迁移文档获取详细说明。

快照和空投

AIB1 快照

在特定区块高度对 AIB1 代币持有量进行了快照，以确定 AIB2 代币分发的资格。快照数据存储在：

  • /scripts/genesis/aib1_snapshot.json
  • /scripts/genesis/snapshot_config.json

空投认领

AIB1 持有者可以通过迁移界面认领其 AIB2 代币。认领流程需要：

  • 证明 AIB1 私钥所有权
  • 签名验证
  • 跨链桥接交易（适用于 BTC/ETH/SOL 持有者）

使用网页钱包认领您的迁移代币。

跨链迁移

AIB 2.0 支持从多条链迁移：

  • 从比特币（BTC）：通过包装代币桥接
  • 从以太坊（ETH）：ERC-20 桥接
  • 从索拉纳（SOL）：SPL 代币桥接
  • 从 AIB1：直接快照映射
