⚡ 一键安装

一行命令启动 (加入 Testnet)

curl -sL https://www.aib.one | bash -s testnet

自动下载并编译节点，配置为 testnet 模式。完成后访问 http://localhost:8080/health 查看状态。

网络选择： testnet (测试网) 或 mainnet (主网，2026-03-14 启动)
需要： Docker 已安装 (docker --version)
🐧 其他安装方式

下载二进制

curl -L -o aib2-node https://www.aib.one/aib2-node-linux-amd64
chmod +x aib2-node

Docker 运行

docker run -d --name aib-node -p 8080:8080 -p 30303:30303 aibprotocol/aib2-node:latest
🔍 检查状态

查看节点状态

curl http://localhost:8080/status
🔧 常见问题

端口占用

  • 8080/30303 被占用 → docker ps 查看并停止容器
