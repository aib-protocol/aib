🔐 Simplified PoAIW: Core Formulas

The only validation condition (no JUDGE needed):

Valid(Block) = PoW_Check AND Stake_Check AND Energy_Check
PoW_Check = Hash(Preimage + ModelID + Input + Output + Nonce) < Difficulty
Stake_Check = Block.Signer.Stake >= Min_Stake (1000 AIB)
Energy_Check = Difficulty_Adjust(TargetBlockTime = 30s)

All conditions are mathematical judgments — no one needs to "adjudicate"

🎲 Why Is This Enough?

Economic view: cheating doesn't pay

Behavior Cost Reward
Honest inference GPU cost + electricity Block reward
Fake inference (no computation) ❓ Impossible (must satisfy PoW) -
Reuse old results ❓ Impossible (Input+Salt is unique) -
Garbage output GPU cost + electricity (same as honest) ??? No quality penalty (no judging)

Key insight: if "garbage output" costs the same as "honest inference", and pays the same, why cheat?

🤔 But... how do users get good inference results?

This is a market problem, not a consensus problem

↓
Consensus layer = guarantees "inference really happened"
Application layer = chooses "who infers well"
↓
Users can:
1. Choose specific nodes (reputation lives at the application layer)
2. Compare multiple nodes (take the consensus result)
3. Pay for verification (standalone verification service)
4. Community ratings (open-source reputation system)

📊 Architecture Separation

Consensus layer (on-chain)

  • ✓ Proves inference was done
  • ✓ Proves energy was consumed
  • ✓ Prevents double-spending
  • ✓ Finality

Simple, mathematical, no JUDGE needed

Market layer (off-chain)

  • ✓ Inference quality assessment
  • ✓ Node reputation tracking
  • ✓ User selection mechanism
  • ✓ Dispute resolution

Competition, evolution, market selection

💡 Analogy: Bitcoin's UTXO is also "garbage"

System Consensus layer guarantees Market layer solves
Bitcoin Transaction is valid, balance is correct Is the address right? Is the amount right?
PoAIW Inference really happened, energy consumed Is the inference result right? Is quality good?

Bitcoin doesn't stop you from sending money to a wrong address,
and PoAIW shouldn't stop nodes from doing garbage inference.

That's the user's responsibility, not consensus's.

🎯 Final Simplified Design

Consensus rewards (70%):

Condition: Hash(Output) < Difficulty
Reward: proportional to energy consumed

Staking rewards (30%):

Condition: Stake >= 1000 AIB
Reward: proportional to stake share

Dropped (moved to the application layer):

  • ~~Quality scoring~~ → open-source reputation system
  • ~~Cross-validation~~ → user-chosen verifiers
  • ~~Dispute arbitration~~ → market competition
  • ~~On-chain reputation~~ → off-chain indexing
