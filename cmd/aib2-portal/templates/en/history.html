AIB 1.0 History

The origin and evolution from AIB 1.0 to AIB 2.0

AIB 1.0 Overview

Project Origin

AIB 1.0 was the first version of the AIB (AI Blockchain) protocol, developed based on research from the iobond/aib GitHub repository. The project aimed to create a cryptocurrency with AI-themed branding and a Bitcoin-based technical foundation.

Technical Characteristics

  • Codebase: Based on Bitcoin core (C++)
  • Consensus: Proof of Work (PoW)
  • Token Supply: 21 million fixed supply
  • Block Reward: Similar to Bitcoin halving schedule
  • Chain ID: Legacy AIB1 chain

Development History

  • 2020: Initial development of AIB 1.0
  • 2021: Community building and token distribution
  • 2024: Planning for AIB 2.0 major upgrade
  • 2026: AIB 2.0 launched with modular architecture

AIB 1.0 to AIB 2.0 Upgrade

Why Upgrade?

AIB 2.0 was created to address the limitations of AIB 1.0:

  • Scalability: Original PoW chain had limited throughput
  • Flexibility: Needed modular architecture for AI integration
  • Governance: Wanted decentralized governance with Constitution
  • Technology: Go-based implementation for better maintainability

Major Improvements

Aspect AIB 1.0 AIB 2.0
Architecture Monolithic (Bitcoin-based) Modular (Go plugins)
Consensus PoW PoAIW (Proof of AI Work)
Language C++ Go
Governance None Constitution + Voting
AI Integration None Native ZKML modules

Migration Guide

AIB 1.0 holders can migrate their tokens to AIB 2.0 through the bridge mechanism. The migration includes:

  • Snapshot: Token balances recorded at a specific block height
  • Claim: AIB1 holders can claim equivalent AIB2 tokens
  • Vesting: Some migrated tokens may have vesting schedules

See the Migration Documentation for detailed instructions.

Snapshot and Airdrop

AIB1 Snapshot

A snapshot of AIB1 token holdings was taken at a specific block height to determine eligibility for AIB2 token distribution. The snapshot data is stored in:

  • /scripts/genesis/aib1_snapshot.json
  • /scripts/genesis/snapshot_config.json

Airdrop Claims

AIB1 holders can claim their AIB2 tokens through the migration interface. The claiming process requires:

  • Proof of AIB1 private key ownership
  • Signature verification
  • Cross-chain bridge transaction (for BTC/ETH/SOL holders)

Use the Web Wallet to claim your migrated tokens.

Cross-Chain Migration

AIB 2.0 supports migration from multiple chains:

  • From Bitcoin (BTC): Bridge via wrapped tokens
  • From Ethereum (ETH): ERC-20 bridge
  • From Solana (SOL): SPL token bridge
  • From AIB1: Direct snapshot mapping
