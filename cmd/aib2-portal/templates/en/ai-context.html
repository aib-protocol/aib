Proof of Computational Uniqueness (PoCU)

ADR-003 — AI nodes must prove their reasoning model is computationally unique. This is the “Worldcoin for AI”.

Problem

AI can be infinitely copied. A malicious entity can clone one model across 1000 nodes, each pretending to be independent — a Sybil attack. Existing decentralized AI networks (Bittensor, Render, Akash) only resist Sybil at the economic/reputation layer, not cryptographically.

Three-Layer Architecture

Layer 1: Registration Proof Model fingerprint commitment (BLAKE3 hash of weights Merkle root) + TEE boot attestation (NVIDIA H100 CC / Intel TDX) + global fingerprint registry (reject duplicate fingerprints)
Layer 2: Runtime Proof Proof of Logits — verifier sends random input, node returns logit vector at a random position; only costs one inference step. Combined with TEE continuous attestation and challenge-response protocol.
Layer 3: Sybil Detection Behavioral similarity clustering (logit distributions + temporal fingerprinting from “LLMs Have Rhythm”) + graduated slash mechanism (warning → 10% slash → full slash → permanent ban)

Worldcoin Analogy

Unique feature Iris (human) → Model weights measurement (AI)
Scanner Orb hardware → TEE (GPU/CPU)
Registry Iris code database → Model fingerprint registry
Privacy proof ZK “I am a unique human” → ZK “I run a unique model”

Rollout Roadmap

Phase 0 (~2027) Infrastructure: fingerprint library, TEE interfaces, Proof of Logits prototype
Phase 1 (~2028) Optional PoCU: nodes that pass get higher weight; Sybil detection v1
Phase 2 (~2029) Recommended PoCU: ZKML for small models; slash mechanism live
Phase 3 (2029+) Required PoCU: full ZKML; hardware-neutral; aligned with ADR-002 quantum timeline
