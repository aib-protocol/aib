⚡ One Command Install

Start node instantly (Join Testnet)

curl -sL https://www.aib.one | bash -s testnet

Auto downloads and compiles node, configured for testnet. Visit http://localhost:8080/health when done.

Network choice: testnet (test) or mainnet (launches 2026-03-14)
Requirement: Docker installed (docker --version)
🐧 Other Options

Download Binary

curl -L -o aib2-node https://www.aib.one/aib2-node-linux-amd64
chmod +x aib2-node

Docker Run

docker run -d --name aib-node -p 8080:8080 -p 30303:30303 aibprotocol/aib2-node:latest
🔍 Check Status

Node Status

curl http://localhost:8080/status

Port Issues

  • 8080/30303 in use → docker ps to check
