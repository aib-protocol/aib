🛡️ 反寡头机制：数学武器

分散度奖励机制详解

分散度奖励 = min(2.0, ln(节点数量 + 1) / 10)

❌ 传统 PoS

  • 质押奖励: 60%
  • 推理奖励: 40%
  • 分散度奖励: 0%

结果：富者越富，寡头形成

✅ PoAIW 2.0

  • 质押奖励: 30%
  • 推理奖励: 70%
  • 分散度奖励: 额外 20%

结果：鼓励贡献，防止垄断

// 反寡头算法实现 (Go 示例) func CalculateAntiOligarchyFactor(stake, totalStake uint64, nodeCount int) float64 { concentration := float64(stake) / float64(totalStake) dispersion := math.Log(float64(nodeCount + 1)) // 集中度惩罚: 份额越大，惩罚越重 punishment := 1.0 / (1.0 + math.Exp(-10*(concentration-0.1))) // 分散度奖励: 节点越多，奖励越高 reward := math.Min(dispersion/10, 2.0) return (1.0 - punishment) * reward }

激励机制设计原理

分散度奖励 = min(2.0, ln(节点数量 + 1) / 10)
集中度惩罚 = 1 / (1 + exp(-10×(份额占比 - 10%)))

注：当单个节点质押超过总质押的 10% 时开始惩罚，最大惩罚 90%。
分散度奖励在 5000 节点时达到上限 2.0 倍。
