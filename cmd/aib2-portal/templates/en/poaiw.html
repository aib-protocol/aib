// Anti-oligarchy algorithm implementation (Go example) func CalculateAntiOligarchyFactor(stake, totalStake uint64, nodeCount int) float64 { concentration := float64(stake) / float64(totalStake) dispersion := math.Log(float64(nodeCount + 1)) // Concentration penalty: the larger the share, the heavier the punishment punishment := 1.0 / (1.0 + math.Exp(-10*(concentration-0.1))) // Decentralization bonus: the more nodes, the higher the reward reward := math.Min(dispersion/10, 2.0) return (1.0 - punishment) * reward }

Incentive Mechanism Design Rationale

Decentralization bonus = min(2.0, ln(node_count + 1) / 10)
Concentration penalty = 1 / (1 + exp(-10×(share − 10%)))

Note: penalties begin when a single node's stake exceeds 10% of total stake, capped at a 90% penalty.
The decentralization bonus reaches its cap of 2.0× at 5,000 nodes.
