二、七层防御体系

Layer 1: 工作量证明 (PoW 基础)

原理：强制执行实际推理计算，无法伪造

ProofOfWork = Hash(Model+Input+Salt+Nonce) < Difficulty

每个推理请求包含随机 Salt，必须用实际推理结果计算 PoW 才能提交

  • 计算成本 预期推理时间 = GPU实际耗时
  • 验证成本 复核节点抽样验证

Layer 2: 多重验证交叉验证

验证类型 参与节点 奖励/惩罚
主验证 3个随机节点 (K=3) ✓ 正确: +3% | ✗ 错误: -10%
交叉验证 5个额外节点 ✓ 一致: +1% | ✗ 偏差: -5%
争议仲裁 21个委员会节点 ✓ 举报成功: +50% 惩罚金

Layer 3: 模型质量证明

防止用最小模型/随机输出刷量：

QualityScore = F1_Score × Semantic_Similarity × Model_Size_Weight
模型规模 质量权重 最低 F1 要求
< 1B 0.3× 0.85
1B - 7B 0.6× 0.90
7B - 70B 1.0× 0.92
> 70B 1.3× 0.94

低于质量阈值的推理 = 0 奖励 + 声誉惩罚

Layer 4: 挑战-响应博弈

任何节点可以挑战已提交的推理结果：

挑战成本 = 100 AIB (抵押)
挑战成功 = 获得 50% 惩罚金 + 返还抵押
挑战失败 = 没收抵押 → 挑战者奖励池
  • 黄金样本集：10,000+ 已知答案的基准问题
  • 随机抽查：5% 的推理被发送验证请求重算
  • 语义一致性：相同输入必须产生语义相似结果

Layer 5: 声誉系统

Reputation = Σ(Reward_i × e^(-λ×age_i)) / (1 + Penalty_Count^2)

声誉影响奖励权重：

声誉等级 奖励系数 验证优先级
新手 (<100) 0.5× 低
信任 (100-500) 1.0× 中
优质 (500-1000) 1.3× 高
旗舰 (>1000) 1.5× 最高

单次作弊 = 声誉 -50%，多次 = 永久封禁

Layer 6: 经济约束

净收益 = 推理奖励 - Gas成本 - 质押机会成本 - 预期惩罚
约束 数值 作用
节点最低质押 1,000 AIB 提高女巫成本
每次推理 Gas 0.01 AIB 垃圾推理成本
错误惩罚倍数 10× 高风险震慑
挑战抵押 100 AIB 减少恶意挑战

Layer 7: 速率限制与配额

防止单点刷量：

DailyQuota = Staking_Amount × Base_Rate × Reputation_Multiplier
质押等级 日推理上限
1,000 AIB 1,000 次
10,000 AIB 15,000 次
100,000 AIB 200,000 次

超出配额 = 奖励衰减 90%

三、攻击成本-收益分析

攻击类型 攻击成本 预期收益 盈利性
缓存攻击 0 AIB -1000 AIB/次 (被捕获) ❌ 亏损
垃圾推理 ~50 AIB/GPU天 0 AIB (质量不达标) ❌ 亏损
3节点合谋 3000 AIB 质押 +500 AIB 后被惩罚 ❌ 亏损
女巫攻击 1000 AIB/节点 × 100节点 0 (配额限制) ❌ 亏损
诚实推理 ~200 AIB/GPU天 ~300 AIB/天 ✅ 盈利

四、关键公式总结

最终推理奖励 = Base_Reward × Quality_Score × Reputation_Multiplier
× (1 - Penalty_Rate) × Anti_Gaming_Factor
Anti_Gaming_Factor = min(1, Daily_Quota / Actual_Requests)

五、实施建议

  1. 主网启动：启用 Layer 1, 2, 6, 7 (基础防御)
  2. 3个月后：启用 Layer 3 (模型质量) + Layer 5 (声誉)
  3. 6个月后：启用 Layer 4 (挑战系统) + 完整经济模型

结论

通过 七层防御，使攻击成本远超诚实参与收益，
确保系统的 纳什均衡 是诚实推理。
