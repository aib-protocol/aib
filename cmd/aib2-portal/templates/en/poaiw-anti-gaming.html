🛡️ PoAIW Anti-Gaming Mechanism

1. Attack Vector Analysis

⚠️ Attack Vectors

1. Cache attack
Return stale cached inference results
2. Garbage inference
Pad volume with the smallest model / random output
3. Result collusion
Multiple nodes collude to verify each other
4. Sybil attack
Create large numbers of fake nodes
5. Early termination
Return a result mid-inference

💰 Attack Motivation

Inference rewards make up 70%of the block reward, so attackers have a strong incentive to farm:

Assumption: 50 AIB/block, 30s/block
Daily blocks: 2,880
Daily inference rewards: 100,800 AIB ≈ $10,000+

2. Seven-Layer Defense System

Layer 1: Proof of Work (PoW Foundation)

Principle: enforces real inference computation that cannot be faked

ProofOfWork = Hash(Model+Input+Salt+Nonce) < Difficulty

Every inference request includes a random Salt; the PoW must be computed over the actual inference result to submit

  • Compute cost Expected inference time = actual GPU time
  • Verification cost review nodes verify by sampling

Layer 2: Multi-Layer Cross-Verification

Verification Type Participating Nodes Reward/Penalty
Primary verification 3 random nodes (K=3) ✓ Correct: +3% | ✗ Wrong: -10%
Cross-validation 5 additional nodes ✓ Consistent: +1% | ✗ Deviation: -5%
Dispute arbitration 21 committee nodes ✓ Successful report: +50% of the penalty

Layer 3: Model Quality Proof

Prevents farming with minimal models / random output:

QualityScore = F1_Score × Semantic_Similarity × Model_Size_Weight
Model Size Quality Weight Minimum F1 Requirement
< 1B 0.3× 0.85
1B - 7B 0.6× 0.90
7B - 70B 1.0× 0.92
> 70B 1.3× 0.94

Inference below the quality threshold = 0 reward + reputation penalty

Layer 4: Challenge-Response Game

Any node can challenge a submitted inference result:

Challenge cost = 100 AIB (deposit)
Successful challenge = 50% of the penalty + deposit returned
Failed challenge = deposit forfeited → challenger reward pool
  • Golden sample set:10,000+ benchmark questions with known answers
  • Random spot checks:5% of inferences get re-computed on verification request
  • Semantic consistency:The same input must produce semantically similar results

Layer 5: Reputation System

Reputation = Σ(Reward_i × e^(-λ×age_i)) / (1 + Penalty_Count^2)

Reputation affects reward weight:

Reputation Tier Reward Multiplier Verification Priority
Novice (<100) 0.5× Low
Trusted (100-500) 1.0× Medium
Quality (500-1000) 1.3× High
Flagship (>1000) 1.5× Highest

One cheat = reputation -50%; repeat offenses = permanent ban

Layer 6: Economic Constraints

Net revenue = inference reward − gas cost − staking opportunity cost − expected penalty
Constraint Value Effect
Minimum node stake 1,000 AIB Raises Sybil cost
Gas per inference 0.01 AIB Cost of garbage inference
Error penalty multiplier 10× High-risk deterrence
Challenge deposit 100 AIB Reduces malicious challenges

Layer 7: Rate Limiting & Quotas

Prevents farming from a single point:

DailyQuota = Staking_Amount × Base_Rate × Reputation_Multiplier
Stake Tier Daily Inference Cap
1,000 AIB 1,000
10,000 AIB 15,000
100,000 AIB 200,000

Exceeding quota = 90% reward decay

3. Attack Cost-Benefit Analysis

Attack Type Attack Cost Expected Gain Profitability
Cache attack 0 AIB -1000 AIB/attempt (caught) ❌ Loss
Garbage inference ~50 AIB/GPU-day 0 AIB (below quality bar) ❌ Loss
3-node collusion 3000 AIB stake +500 AIB then penalized ❌ Loss
Sybil attack 1000 AIB/node × 100 nodes 0 (quota limited) ❌ Loss
Honest inference ~200 AIB/GPU-day ~300 AIB/day ✅ Profitable

4. Key Formula Summary

Final inference reward = Base_Reward × Quality_Score × Reputation_Multiplier
× (1 - Penalty_Rate) × Anti_Gaming_Factor
Anti_Gaming_Factor = min(1, Daily_Quota / Actual_Requests)

5. Implementation Recommendations

  1. Mainnet launch:enable Layers 1, 2, 6, 7 (basic defenses)
  2. After 3 months:enable Layer 3 (model quality) + Layer 5 (reputation)
  3. After 6 months:enable Layer 4 (challenge system) + the full economic model

Conclusion

The Seven-layer defense pushes attack costs far above the returns of honest participation,
ensuring the system's Nash equilibrium is honest inference.
