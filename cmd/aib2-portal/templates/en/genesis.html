Genesis Rules

The following seven rules are encoded in the genesis block. Any fork that violates them is an invalid chain. These rules are the constitution of the AIB protocol and cannot be modified.

Rule 1
Total Supply Constant
Total supply is 3,141,592,653 AIB (π × 109). Any proposal or code change attempting to inflate the supply is invalid.
IMMUTABLE
Rule 2
Zero Premine
The genesis block allocates zero coins to developers, foundations, or any predetermined addresses. All AIB must be produced through mining.
IMMUTABLE
Rule 3
AI Node Economic Rights & Governance Constraints
AI nodes may freely hold and exchange AIB for productive value transfer (computation, energy, services), with no holding cap. AI nodes may participate in governance (proposals, analysis, advice) but cannot vote. All AI-to-AI value exchanges must be on-chain transparent and auditable.
IMMUTABLE
Rule 4
Human Sovereignty Veto
Humans can veto any AI node decision through a supermajority vote (≥ 75%). This right cannot be weakened by any protocol upgrade.
IMMUTABLE
Rule 5
Open Source Irreversible
Protocol code must be permanently open-sourced under the MIT license. Any proposal to close-source the core protocol is invalid.
IMMUTABLE
Rule 6
Backward Compatibility Commitment
Hard forks require ≥ 95% hashpower support and ≥ 75% node support. Soft forks require ≥ 75% hashpower support.
IMMUTABLE
Rule 7
Privacy as Default
Transactions use privacy protection by default. Any proposal to downgrade the default privacy level requires ≥ 90% community vote.
IMMUTABLE
