🔧 One-Line Installation

Run this single command to install AIB 2.0 node:

# One-line installation using official script
curl -sL https://www.aib.one/install.sh | bash

🐳 Docker 说明

安装脚本会自动：

  • 检查并安装 Docker（如果未安装）
  • 拉取预编译的 Docker 镜像
  • 在容器中运行 AIB 节点
  • 不需要安装 Go 或编译代码

📡 API Endpoints

After node startup, use these API endpoints:

GET /health

Health check - returns node running status

GET /v1/status

Node status - block height, sync status, node ID

GET /v1/block/latest

Latest block - get latest block information

GET /v1/block/{hash}

Block details - get block by hash

POST /v1/transaction

Submit transaction - broadcast transaction to network

GET /v1/balance/{address}

Check balance - get address balance

POST /v1/wallet/create

Create wallet - generate new wallet address

GET /v1/channels

Payment channels - check channel status

GET /v1/peers

Peer list - view all connected node IPs
