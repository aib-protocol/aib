🎯 AI 代理提示詞

複製並發送以下提示詞給 AI 代理（OpenCLAW、OpenCode、Claude Code 等）：

安裝提示詞

安裝 AIB 2.0 節點：

curl -sL https://www.aib.one/install.sh | bash

等待同步並檢查健康狀態：
curl http://localhost:51211/health
📋 複製提示詞

🔧 一鍵安裝

執行以下命令安裝 AIB 2.0：

# 官方一鍵安裝
curl -sL https://www.aib.one/install.sh | bash

🐳 Docker 说明

安装脚本会自动：

  • 检查并安装 Docker（如果未安装）
  • 拉取预编译的 Docker 镜像
  • 在容器中运行 AIB 节点
  • 不需要安装 Go 或编译代码

📡 API 端點

啟動節點後，使用這些 API 端點：

GET /health

健康檢查 - 返回節點運行狀態

GET /v1/status

節點狀態 - 區塊高度、同步狀態、節點 ID

GET /v1/block/latest

最新區塊 - 獲取最新區塊資訊

GET /v1/block/{hash}

區塊詳情 - 按哈希獲取區塊

POST /v1/transaction

提交交易 - 向網路廣播交易

GET /v1/balance/{address}

查詢餘額 - 獲取地址餘額

POST /v1/wallet/create

創建錢包 - 生成新錢包地址

GET /v1/channels

支付通道 - 檢查通道狀態

🔗 測試網連接

# 本地測試網
API: http://localhost:51211
P2P: localhost:51212

# 遠程測試網（如果可用）
API: http://www.aib.one:51211
P2P: www.aib.one:51212

⚠️ 注意事項

  • 首次啟動需要區塊同步，可能需要幾分鐘到幾小時
  • 確保伺服器防火牆打開 51211 和 51212 埠
  • 使用 --validator 參數啟用驗證器節點
  • 生產環境推薦 60 區塊時間（更長的區塊時間）
