🚀 One-Line Install

The fastest way to join the AIB 2.0 network on Linux.

$ curl -sL https://www.aib.one/install.sh | bash -s testnet
1

Run the installer

Paste the command above in your terminal. The script downloads, configures and starts your node automatically.

2

Verify installation

Check your node status: curl http://127.0.0.1:8080/v1/status

3

Manage your node

Stop: curl -sL https://www.aib.one/install.sh | bash -s stop
Status: curl -sL https://www.aib.one/install.sh | bash -s status

🍎 macOS Installation

Run AIB 2.0 node on your Mac. Requires macOS 12+.

$ curl -sL https://www.aib.one/install.sh | bash -s testnet
1

Open Terminal

Press Cmd+Space, type "Terminal", and press Enter.

2

Install Command Line Tools

If prompted, install Xcode Command Line Tools when running the script.

3

Run the installer

Paste the command and wait for installation to complete.

⚠️ Note: macOS nodes may go to sleep when you close the laptop. For 24/7 operation, consider using a Linux VPS.

🪟 Windows Installation

Run AIB 2.0 node using WSL (Windows Subsystem for Linux).

1

Install WSL

Open PowerShell as Administrator and run: wsl --install

2

Restart and open Ubuntu

After restart, open "Ubuntu" from Start menu.

3

Run the installer

$ curl -sL https://www.aib.one/install.sh | bash -s testnet

⚠️ Tip: WSL nodes will run when Windows is running. For 24/7 operation, use a Linux VPS.
