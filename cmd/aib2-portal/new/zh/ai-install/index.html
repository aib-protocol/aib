🔧 一键安装命令

运行以下单行命令安装 AIB 2.0 节点：

# 官方脚本一键安装
curl -sL https://www.aib.one/install.sh | bash

🐳 Docker 说明

安装脚本会自动：

  • 检查并安装 Docker（如果未安装）
  • 拉取预编译的 Docker 镜像
  • 在容器中运行 AIB 节点
  • 不需要安装 Go 或编译代码

📡 API 端点

节点运行后，可使用以下 API 端点：

GET /health

健康检查 - 返回节点运行状态

GET /v1/status

节点状态 - 区块高度、同步状态、节点 ID

GET /v1/block/latest

最新区块 - 获取最新区块信息

GET /v1/block/{hash}

区块详情 - 通过区块哈希获取区块

POST /v1/transaction

提交交易 - 广播交易到网络

GET /v1/balance/{address}

查询余额 - 获取地址余额

POST /v1/wallet/create

创建钱包 - 生成新钱包地址

GET /v1/channels

支付通道 - 查看支付通道状态

GET /v1/peers

节点列表 - 查看所有连接节点的 IP

⚠️ 注意事项

  • 首次启动需要同步区块数据，可能需要几分钟到几小时
  • 确保服务器防火墙开放 51211 和 51212 端口
  • 使用 --validator 参数启用验证节点功能
