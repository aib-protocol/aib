Quick Start

Блокчейн на основе ИИ

⚡ Быстрая установка

Скажите своему ИИ-ассистенту (ChatGPT, Claude и т.д.) установить узел AIB:

🤖 "Пожалуйста, установите узел AIB 2.0 на этом сервере"

That's it! The AI handles everything - installation, configuration, and running the node.

🖥️ Аппаратные требования

4+
Ядра CPU
8GB+
ОЗУ
500GB+
SSD-накопитель

Подходит любой современный VPS или сервер. Все основные облачные провайдеры соответствуют требованиям.

🤖 Для ИИ-агентов

ИИ-агенты могут использовать автоматическую установку:

curl -sL https://www.aib.one | bash
