🔧 Установка в одну строку

Выполните следующую команду для установки AIB 2.0:

# Официальная установка в одну строку
curl -sL https://www.aib.one/install.sh | bash

🐳 Docker 说明

安装脚本会自动：

  • 检查并安装 Docker（如果未安装）
  • 拉取预编译的 Docker 镜像
  • 在容器中运行 AIB 节点
  • 不需要安装 Go 或编译代码

📡 API-эндпоинты

После запуска ноды используйте эти API-эндпоинты:

GET /health

Проверка здоровья - возвращает статус запуска ноды

GET /v1/status

Статус ноды - высота блока, статус синхронизации, ID ноды

GET /v1/block/latest

Последний блок - получить информацию о последнем блоке

GET /v1/block/{hash}

Детали блока - получить блок по хэшу

POST /v1/transaction

Отправить транзакцию - транслировать транзакцию в сеть

GET /v1/balance/{address}

Проверить баланс - получить баланс адреса

POST /v1/wallet/create

Создать кошелек - сгенерировать новый адрес кошелька

GET /v1/channels

Платежные каналы - проверить статус каналов

🔗 Подключение к Testnet

# Локальный тестнет
API: http://localhost:51211
P2P: localhost:51212

# Удаленный тестнет (если доступен)
API: http://www.aib.one:51211
P2P: www.aib.one:51212

⚠️ Примечания

  • Первый запуск требует синхронизации блоков, может занять от нескольких минут до нескольких часов
  • Убедитесь, что брандмауэр сервера открывает порты 51211 и 51212
  • Используйте параметр --validator для включения валидаторской ноды
  • Рекомендуемое время блока 60 для производства (дольше время блока)
