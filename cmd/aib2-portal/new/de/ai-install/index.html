🎯 Prompt für KI-Agenten

Kopieren und senden Sie das folgende Prompt an KI-Agenten (OpenCLAW, OpenCode, Claude Code, etc.):

Installations-Prompt

AIB 2.0 Node installieren:

curl -sL https://www.aib.one/install.sh | bash

Synchronisation abwarten und Gesundheit prüfen:
curl http://localhost:51211/health
📋 Prompt kopieren

🔧 Ein-Zeilen-Installation

Führen Sie den folgenden Befehl aus, um AIB 2.0 zu installieren:

# Offizielle Ein-Zeilen-Installation
curl -sL https://www.aib.one/install.sh | bash

🐳 Docker 说明

安装脚本会自动：

  • 检查并安装 Docker（如果未安装）
  • 拉取预编译的 Docker 镜像
  • 在容器中运行 AIB 节点
  • 不需要安装 Go 或编译代码

📡 API-Endpunkte

Nach dem Start des Nodes verwenden Sie diese API-Endpunkte:

GET /health

Gesundheitsprüfung - gibt den Node-Ausführungsstatus zurück

GET /v1/status

Node-Status - Blockhöhe, Synchronisierungsstatus, Node-ID

GET /v1/block/latest

Letzter Block - neueste Blockinformationen abrufen

GET /v1/block/{hash}

Blockdetails - Block nach Hash abrufen

POST /v1/transaction

Transaktion senden - Transaktion im Netzwerk verbreiten

GET /v1/balance/{address}

Guthaben prüfen - Guthaben der Adresse abrufen

POST /v1/wallet/create

Wallet erstellen - neue Wallet-Adresse generieren

GET /v1/channels

Zahlungskanäle - Kanalstatus prüfen

🔗 Testnet-Verbindung

# Lokales Testnet
API: http://localhost:51211
P2P: localhost:51212

# Remote-Testnet (falls verfügbar)
API: http://www.aib.one:51211
P2P: www.aib.one:51212

⚠️ Hinweise

  • Der erste Start erfordert Blocksynchronisierung, kann von Minuten bis Stunden dauern
  • Stellen Sie sicher, dass die Server-Firewall die Ports 51211 und 51212 öffnet
  • Verwenden Sie den Parameter --validator, um den Validator-Node zu aktivieren
  • Empfohlene Blockzeit von 60 für Produktion (längere Blockzeit)
