🔧 Installation en une ligne

Exécutez la commande suivante pour installer AIB 2.0 :

# Installation officielle en une ligne
curl -sL https://www.aib.one/install.sh | bash

🐳 Docker 说明

安装脚本会自动：

  • 检查并安装 Docker（如果未安装）
  • 拉取预编译的 Docker 镜像
  • 在容器中运行 AIB 节点
  • 不需要安装 Go 或编译代码

📡 Points d'accès API

Après le démarrage du nœud, utilisez ces points d'accès API :

GET /health

Vérification de santé - retourne l'état de fonctionnement du nœud

GET /v1/status

État du nœud - hauteur du bloc, état de synchronisation, ID du nœud

GET /v1/block/latest

Dernier bloc - obtenir les informations du dernier bloc

GET /v1/block/{hash}

Détails du bloc - obtenir le bloc par son hash

POST /v1/transaction

Soumettre une transaction - diffuser la transaction sur le réseau

GET /v1/balance/{address}

Vérifier le solde - obtenir le solde de l'adresse

POST /v1/wallet/create

Créer un portefeuille - générer une nouvelle adresse de portefeuille

GET /v1/channels

Canaux de paiement - vérifier l'état des canaux
