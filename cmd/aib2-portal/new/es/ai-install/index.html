🔧 Instalación en una línea

Ejecute el siguiente comando para instalar AIB 2.0:

# Instalación oficial en una línea
curl -sL https://www.aib.one/install.sh | bash

🐳 Docker 说明

安装脚本会自动：

  • 检查并安装 Docker（如果未安装）
  • 拉取预编译的 Docker 镜像
  • 在容器中运行 AIB 节点
  • 不需要安装 Go 或编译代码

📡 Endpoints API

Después de iniciar el nodo, use estos endpoints API:

GET /health

Verificación de salud - devuelve el estado de ejecución del nodo

GET /v1/status

Estado del nodo - altura del bloque, estado de sincronización, ID del nodo

GET /v1/block/latest

Último bloque - obtener información del último bloque

GET /v1/block/{hash}

Detalles del bloque - obtener bloque por hash

POST /v1/transaction

Enviar transacción - transmitir transacción a la red

GET /v1/balance/{address}

Verificar saldo - obtener saldo de la dirección

POST /v1/wallet/create

Crear cartera - generar nueva dirección de cartera

GET /v1/channels

Canales de pago - verificar estado de los canales

🔗 Conexión a Testnet

# Testnet local
API: http://localhost:51211
P2P: localhost:51212

# Testnet remoto (si está disponible)
API: http://www.aib.one:51211
P2P: www.aib.one:51212

⚠️ Notas

  • El primer inicio requiere sincronización de bloques, puede tomar desde minutos hasta horas
  • Asegúrese de que el firewall del servidor abra los puertos 51211 y 51212
  • Use el parámetro --validator para habilitar el nodo validador
  • Tiempo de bloque recomendado de 60 para producción (tiempo de bloque más largo)
