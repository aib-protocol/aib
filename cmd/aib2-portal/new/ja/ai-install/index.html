🎯 AIエージェントへのプロンプト

以下のプロンプトをコピーしてAIエージェントに送信してください（OpenCLAW、OpenCode、Claude Codeなど）：

インストールプロンプト

AIB 2.0ノードをインストール：

curl -sL https://www.aib.one/install.sh | bash

同期を待ってヘルスチェック：
curl http://localhost:51211/health
📋 プロンプトをコピー

🔧 ワンラインインストール

以下のコマンドでAIB 2.0をインストール：

# 公式スクリプトでワンラインインストール
curl -sL https://www.aib.one/install.sh | bash

🐳 Docker 说明

安装脚本会自动：

  • 检查并安装 Docker（如果未安装）
  • 拉取预编译的 Docker 镜像
  • 在容器中运行 AIB 节点
  • 不需要安装 Go 或编译代码

📡 APIエンドポイント

ノード起動後、これらのAPIエンドポイントを使用できます：

GET /health

ヘルスチェック - ノード実行状態を返す

GET /v1/status

ノード状態 - ブロック高さ、同期状態、ノードID

GET /v1/block/latest

最新ブロック - 最新ブロック情報を取得

GET /v1/block/{hash}

ブロック詳細 - ハッシュでブロックを取得

POST /v1/transaction

トランザクション送信 - ネットワークにトランザクションをブロードキャスト

GET /v1/balance/{address}

残高確認 - アドレスの残高を取得

POST /v1/wallet/create

ウォレット作成 - 新しいウォレットアドレスを生成

GET /v1/channels

ペイメントチャンネル - チャンネル状態を確認

🔗 テストネット接続

# ローカルテストネット
API: http://localhost:51211
P2P: localhost:51212

# リモートテストネット（利用可能な場合）
API: http://www.aib.one:51211
P2P: www.aib.one:51212

⚠️ 注意事項

  • 初回起動時はブロック同期が必要で、数分から数時間かかる場合があります
  • サーバーのファイアウォールで51211と51212ポートを開放してください
