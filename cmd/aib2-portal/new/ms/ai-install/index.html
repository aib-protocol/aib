curl -sL https://www.aib.one/install.sh | bash

🐳 Docker 说明

安装脚本会自动：

  • 检查并安装 Docker（如果未安装）
  • 拉取预编译的 Docker 镜像
  • 在容器中运行 AIB 节点
  • 不需要安装 Go 或编译代码

📡 Endpoint API

Selepas pelancaran nod, gunakan endpoint API ini:

GET /health

Pemeriksaan kesihatan - mengembalikan status nod

GET /v1/status

Status nod - ketinggian blok, status penyegerakan, ID nod

GET /v1/block/latest

Blok terkini - dapat maklumat blok terkini

GET /v1/block/{hash}

Butiran blok - dapat blok mengikut hash

POST /v1/transaction

Hantar transaksi - siaran transaksi ke rangkaian

GET /v1/balance/{address}

Semak baki - dapat baki alamat

POST /v1/wallet/create

Cipta wallet - janakan alamat wallet baharu

GET /v1/channels

Saluran pembayaran - semak status saluran
