  • 不需要安装 Go 或编译代码

📡 API Endpoints

หลังจากเริ่มโหนด ให้ใช้ API endpoints เหล่านี้:

GET /health

การตรวจสอบสุขภาพ - ส่งคืนสถานะการทำงานของโหนด

GET /v1/status

สถานะโหนด - ความสูงบล็อก, สถานะการซิงโครไนซ์, ID โหนด

GET /v1/block/latest

บล็อกล่าสุด - รับข้อมูลบล็อกล่าสุด

GET /v1/block/{hash}

รายละเอียดบล็อก - รับบล็อกตาม hash

POST /v1/transaction

ส่งธุรกรรม - กระจายธุรกรรมไปยังเครือข่าย

GET /v1/balance/{address}

ตรวจสอบยอดเงิน - รับยอดเงินของที่อยู่

POST /v1/wallet/create

สร้างกระเป๋าเงิน - สร้างที่อยู่กระเป๋าเงินใหม่

GET /v1/channels

ช่องทางการชำระเงิน - ตรวจสอบสถานะช่องทาง
