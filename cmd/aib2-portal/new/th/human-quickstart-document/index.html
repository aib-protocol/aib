Quick Start Guide

Get your AIB 2.0 node up and running in minutes. Follow the steps below to install, configure, and join the network.

02

Installation

Clone the repository

Fetch the latest source code from the official repository.

bash 
git clone https://github.com/aib-protocol/aib.git
cd aib
Build the binaries

Compile the node daemon and CLI tool using Go.

bash 
# Build all binaries
make build

# Or build individual targets
go build -o bin/aibd ./cmd/aibd
go build -o bin/aibcli ./cmd/aibcli
Install to system PATH

Make the binaries globally accessible.

bash 
sudo cp bin/aibd /usr/local/bin/
sudo cp bin/aibcli /usr/local/bin/

# Verify installation
aibd version
aibcli version
i

Module path: github.com/aib-protocol/aib. ChainID for mainnet: aib-mainnet-1. Mainnet launch: March 14, 2026 (Pi Day).

03

Configuration Basics

Initialize node configuration

This creates the default config files and genesis document in ~/.aib/.

bash 
aibd init my-node --chain-id aib-mainnet-1
Key configuration parameters

Edit ~/.aib/config/config.toml to adjust these settings:

Parameter Value Description
chain-id aib-mainnet-1 Mainnet chain identifier
moniker your-node-name Human-readable node name
laddr (P2P) tcp://0.0.0.0:26656 P2P listen address
laddr (RPC) tcp://127.0.0.1:26657 RPC listen address
persistent_peers (seed node list) Bootstrap peers for network discovery
timeout_commit 30s Block time (30 second target)
toml - ~/.aib/config/config.toml (excerpt) 
# Node identity
moniker = "my-aib-node"

# P2P configuration
[p2p]
laddr = "tcp://0.0.0.0:26656"
persistent_peers = ""  # Add seed nodes here

# RPC configuration
[rpc]
laddr = "tcp://127.0.0.1:26657"

# Consensus
[consensus]
timeout_commit = "30s"
04

Running a Node

Start the node

Launch the AIB daemon. It will sync from genesis or from a snapshot.

bash 
aibd start
Run as a systemd service (recommended for production)

Create a service file so the node restarts automatically.

bash 
# Create systemd service
sudo tee /etc/systemd/system/aibd.service <<EOF
[Unit]
Description=AIB 2.0 Node
After=network-online.target

[Service]
User=$USER
ExecStart=/usr/local/bin/aibd start
Restart=always
RestartSec=3
LimitNOFILE=65535

[Install]
WantedBy=multi-user.target
EOF

# Enable and start the service
sudo systemctl daemon-reload
sudo systemctl enable aibd
sudo systemctl start aibd

# Monitor logs
journalctl -u aibd -f
i

To become a validator, a minimum stake of 1,000 AIB is required. Block rewards are 50 AIB per block at a 30-second block time. See the Tokenomics page for full details.

05

Creating a Wallet

Generate a new key

Creates a new key pair and stores it in the local keyring. Save the mnemonic phrase securely — it cannot be recovered later.

bash 
# Generate a new wallet
aibcli keys add my-wallet

# Output includes:
#   address:  aib1xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
#   mnemonic: word1 word2 word3 ... (24 words)
Recover an existing wallet

Restore a wallet using a BIP-39 mnemonic phrase.

bash 
aibcli keys add my-wallet --recover
List and inspect keys
bash 
# List all keys
aibcli keys list

# Show a specific key
aibcli keys show my-wallet

# Show validator address
aibcli keys show my-wallet --bech val
!

Never share your mnemonic phrase. Store it offline in a secure location. AIB 2.0 addresses use the aib1 prefix (bech32 encoding).

06

Basic Commands

Check Status
aibd status
Display node sync status, latest block height, and peer count.
Query Balance
aibcli query bank balances <address>
Show token balance for any AIB address.
Send Tokens
aibcli tx bank send <from> <to> <amount>uaib
Transfer AIB tokens between addresses on-chain.
Delegate Stake
aibcli tx staking delegate <validator> <amount>uaib
Delegate tokens to a validator to earn staking rewards.
Query Validators
aibcli query staking validators
List all active validators on the network.
Claim Rewards
aibcli tx distribution withdraw-all-rewards
Withdraw accumulated staking rewards to your wallet.
Query Transaction
aibcli query tx <tx-hash>
Look up the details of any on-chain transaction.
Node Version
aibd version --long
Show full version info including build commit and Go version.
bash - helpful flags 
# Use a specific RPC endpoint
aibcli --node tcp://localhost:26657 query status

# Set chain ID globally
aibcli config chain-id aib-mainnet-1

# Set default keyring backend
aibcli config keyring-backend file

# Output in JSON format
aibcli query bank balances <address> -o json
